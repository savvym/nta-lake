## 跨改动观察

1. **`queries.ts` 变更追踪注释模式**：L111/L175/L257/L325 四处 `// ---` 分隔符，其中 L257 为前驱 change 引入的 pre-existing 风格，L325 为本 change 引入。这是项目内正在蔓延的任务追踪注释模式，建议在下一次 queries.ts 大改时统一清理（SHOULD-2）。

2. **`as never` 类型 cast 在测试中**：`repos.tabs.test.tsx` L75 和 `blob.test.tsx` L37 均使用 `<RouterProvider router={router as never} />`。这是 TanStack Router + vitest 的类型不兼容既知 workaround，与既有 `repos.test.tsx` 中的相同模式一致，不是新引入的问题。

3. **HTML `hidden` attribute vs Tailwind `className="hidden"`**：实现用了 React JSX `hidden={expr}` 属性（对应 HTML hidden attribute），而 spec risk 表和 tasks.md 描述写的是"`hidden` className"。两者运行时效果等价（均为 display:none），tasks.md 的 pseudocode 也是 `hidden={...}` 语法，因此这不是 bug，但表述不一致可能造成未来维护者混淆。
